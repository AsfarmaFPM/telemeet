# 🚀 Asfarma TeleMeet — Онлайн Видеоконференция ва Тақдимотлар Платформаси

> **Asfarma Pharmaceuticals** учун махсус ишлаб чиқилган, Zoom ва Google Meet муқобили бўлган профессионал онлайн видеоконференция ва синхрон тақдимотлар платформаси.

---

## ✨ Асосий Имкониятлар (Features)

1. **🔒 Хавфсиз WebRTC Видеоалоқа (5 дан 50 тагача иштирокчи):**
   - Дастур ёки илова ўрнатмасдан, браузер орқали тўғридан-тўғри уланиш.
   - HD сифатдаги видео ва шовқинни тозаловчи аудио (Echo cancellation, Noise suppression).
   - Сўзловчини автоматик аниқлаш ва ажратиб кўрсатиш (Active Speaker Detection).
   - Бошқарувчи (Host) модерацияси: барчани ўчириш (Mute All), чиқариб юбориш (Kick).

2. **📊 Интерактив Тақдимотлар (Interactive Presentation Mode):**
   - **PowerPoint (PPTX), PDF, Расмлар (PNG/JPG) ва Видео (MP4/WebM)** намойиши.
   - **🔴 Жонли лазер кўрсаткич (Laser Pointer):** Бошловчининг курсори барча қатнашчилар экранида реал вақтда кўринади.
   - **✏️ Интерактив қалам (Annotation Pen):** Слайдлар устида чизмалар ва изоҳлар чизиш.
   - Барча иштирокчилар учун слайдларни 100% синхрон варақлаш.

3. **🖥 Экран Намойиши (Screen Sharing 1080p 60fps):**
   - Компьютердаги **PowerPoint слайд-шоуси (F5)**, алоҳида дастур ойнаси ёки бутун экранни овоз билан бирга намойиш қилиш.

4. **📈 Видеосессия Якуний Ҳисоботи ва Давомат (Attendance & Camera Analytics):**
   - **Умумий давомийлик:** Конференция неча дақиқа ва сония давом этгани сониясигача аниқ ҳисобланади.
   - **Иштирокчилар давомати:** Ҳар бир қатнашчи сессияда неча дақиқа бўлганлиги қайд этилади.
   - **Камера фаоллиги:** Иштирокчилар видеокамераларини неча дақиқа ёқиб тургани ва фаоллик фоизи (%).
   - **📥 Excel / CSV экспорт:** Ҳисоботни бир тугма билан компьютерга юклаб олиш (UTF-8 BOM форматида).
   - **📋 Telegram нусхалаш:** Ҳисоботни гуруҳга ташлаш учун тайёр матн шаклида нусхалаш.

5. **🌐 2 хил тилда интерфейс:**
   - Ўзбекча (`O'Z`) ва Русча (`RU`) тилларни бир кликда танлаш.
   - Asfarma корпоратив оқ ва оранжевый услуби, логотип ва фавикон.

## 🚀 GitHub га юклаш бўйича кўрсатма (Push to GitHub)

Лойиҳа GitHub'га юклаш учун тўлиқ тайёрланган.

### 1-Қадам: GitHub сайтида янги репозиторий очинг
1. [github.com](https://github.com) га киринг ва **New Repository** (Янги репозиторий) тугмасини босинг.
2. Номини ёзинг (масалан: `asfarma-zoom` ёки `telemeet-platform`).
3. **Public** ёки **Private** ни танланг.
4. *«Initialize with README»* га белги **қўйманг** (чунки бизда тайёр файллар бор).
5. **Create repository** тугмасини босинг.

### 2-Қадам: Лойиҳани юклаш (Энг осон йўли)
Папка ичидаги **`PUSH_TO_GITHUB.bat`** файли устига икки марта босинг ва чиққан ойнага GitHub репозиторий ҳаволангизни киритинг!

**ЁКИ буйруқлар сатри (Terminal / PowerShell) орқали:**
```bash
# 1. Лойиҳа папкасига ўтинг:
cd D:\Программы\videoconf-platform

# 2. Ўзингизнинг GitHub ҳаволангизни уланг (USERNAME ва REPO_NAME ни алмаштиринг):
git remote add origin https://github.com/USERNAME/asfarma-zoom.git

# 3. Файлларни юкланг:
git push -u origin main
```

3. GitHub даги `asfarma-zoom` репозиторийингизни танланг (Connect).
4. Қуйидаги созламаларни киритинг:
   - **Name:** `asfarma-zoom`
   - **Runtime:** `Node`

6. 1-2 дақиқада тизим ишга тушади ва сизга доимий бепул ҳавола беради:

## 🛠 Тузатилган хатолар (v1.1)

1. **Экран намойиши тугмаси ишламаётган эди** — очилувчи меню контейнер ичида қирқилиб кетарди. Энди меню `body` га чиқарилган (экран / видео файл танлаш кўринади).
2. **Тақдимот файли бошқа иштирокчиларга кўринмасди** — слайдлар base64 бўлиб socket орқали юборилар, катта файлда уланиш узиларди. Энди слайдлар серверга HTTP орқали юкланади, socket орқали фақат ҳавола кетади. PDF worker ҳам CDN га боғлиқ эмас.
3. **Иккинчи намойиш кўринмасди** — қайта уланишдан кейин хонага қайта кирилмасди, камерасиз компьютерларда аудио/видео каналлар ҳосил бўлмасди. Энди ҳар бир уланишда доимий аудио/видео канал бор, қайта уланишда хонага автоматик қайта кирилади ва ICE қайта ишга туширилади.
4. Бошқа тузатишлар: овоз иккиланиши (экран намойишида), экран/видео овозини узатиш, видео файл учун play/pause/seek, PPTX слайдлар тўғри тартибда, бир вақтда фақат битта намойишчи, тақдимотни фақат тақдимотчи/host тўхтата олади, "ўша файлни қайта танлаш" ишламаслиги, қалам чизмалари кеч уланганларга ҳам кўриниши.

### Янгилангандан кейин
```bash
npm --prefix client install
npm --prefix client run build   # ёки тайёр client/dist дан фойдаланинг
npm start
```
Интернет орқали ишлатганда `client/.env.example` даги **TURN** созламасини ёқиш тавсия этилади.
